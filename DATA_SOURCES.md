# Data sources and expected inputs

The data are not redistributed in this software archive. This archive ships main-figure code only; it reads precomputed event-level files produced by the authors' analysis pipeline, which ultimately derive from the products listed below. Users must obtain the upstream products from their original providers and comply with the applicable terms of use.

## Upstream data products

### NOAA OISST version 2.1

- Role: SST input for grid-cell MHW/MCS detection; the plotted event dataset derives from it
- Persistent identifier: https://doi.org/10.25921/re9p-pt57
- Study detection interval: 2001–2023; climatological interval: 1991–2020

### OCNET chlorophyll-a

- Role: total CHLA input to the event-aligned biological series
- Persistent identifier: https://doi.org/10.5281/zenodo.14691522
- Analysis interval: 2001–2023

### GLORYS12V1

- Role: mixed-layer-depth input to the event-aligned physical series
- Persistent identifier: https://doi.org/10.48670/moi-00021

The model-derived phytoplankton size classes (pico/nano/micro) in the event-level files follow the Brewin (2023) size-class model; the coefficients and equations are published in Supplementary Table S2 of the manuscript.

## Precomputed event-level inputs read by the archived scripts

These intermediate files are outputs of the upstream pipeline and are expected at the following project-relative paths. They are not redistributed and cannot be regenerated from this archive alone.

| Expected path | Content | Read by |
|---|---|---|
| `05_Characteristic/Out/Characteristic_{MHW,MCS}_Basin_Eps5_MinPts200.mat` | Event-level characteristics and aligned CHLA/PSC/MLD response series | `Composite_01`, `Plot_00`, `Plot_03`, `Plot_05`, `Plot_06`, `Plot_07_Physical_Mechanism_MLD_CHLA_PSC`, `Plot_08` |
| `04_Statistic/Out/Statistic_{MHW,MCS}_Basin_Eps5_MinPts200.mat` | Event statistics structures | `Plot_00` |
| `figure_code/In/MLD_{MHW,MCS}_Eps5_MinPts200.mat` | Event-aligned MLD series | `Plot_03`, `Plot_05`, `Plot_07_Physical_Mechanism_MLD_CHLA_PSC`, `Plot_08` |

The plot-data caches under `figure_code/Cache/` are generated by the archived scripts themselves and are not inputs.
