# MHW MCS CHLA main-figure code

Version 1.0.0

This archive contains the code that generates the main-text figures of the manuscript "Global phytoplankton responses to spatiotemporally continuous marine heatwaves and cold spells". The scripts render event-aligned chlorophyll-a (CHLA), model-derived phytoplankton size-class (PSC: pico/nano/micro), and mixed-layer-depth (MLD) responses for spatiotemporally continuous marine heatwaves (SCMHW) and cold spells (SCMCS), grouped by mean intensity, duration, and maximum area.
